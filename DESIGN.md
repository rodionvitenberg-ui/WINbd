# WINbd — дизайн-система (UI/UX)

> Этот документ задаёт визуальную идентичность проекта. Все UI-компоненты обязаны следовать ему — **никаких «сгенерированных вслепую» стилей**.

## 1. Философия

Мы строим **редактор новостных статей** — инструмент, похожий на Medium / Notion: спокойствие, типографика, фокус на контенте. Интерфейс не должен кричать — он должен «исчезать», давая читать и писать.

## 2. Цветовая палитра

Переменные SCSS:

```scss
// Нейтральная база (тёмная тема редактора)
$bg-primary:    #0f1115;   // фон приложения (тёмный)
$bg-surface:    #171a21;   // карточки, панели, блоки
$bg-elevated:   #1f2430;   // выпадающие меню, тулбары
$border-subtle: rgba(255, 255, 255, 0.08);

// Текст
$text-primary:  #e6e9ef;   // основной текст
$text-secondary:#9aa3b2;   // подписи, метаданные
$text-muted:    #5c6470;   // плейсхолдеры

// Акценты
$accent:        #4f8cff;   // фирменный синий (кнопки, активные элементы)
$accent-hover:  #6ba0ff;
$success:       #34d399;   // «опубликовано», успех
$warning:       #fbbf24;   // «черновик», ожидание
$danger:        #f87171;   // удаление, ошибки

// Типографика кода
$code-bg:       #0a0d12;
$code-text:     #b8c4d4;
```

> Тёмная тема выбрана потому, что редакторы кода/текста при длительной работе комфортнее тёмные. Это осознанный выбор, а не умолчание.

## 3. Типографика

- Основной шрифт: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` (нативные системные шрифты — быстрые и всегда доступные).
- Моноширинный (код): `ui-monospace, "Cascadia Code", "JetBrains Mono", Menlo, monospace`.
- Размеры: `16px` база, заголовки — `clamp()` для адаптивности.

```scss
// Типографические стили для блоков контента:
// h1 — заголовок статьи   (34px/1.2, полужирный)
// h2 — подзаголовок       (26px/1.3)
// paragraph — абзац       (17px/1.7)
// quote — цитата          (20px/1.6, курсив, левая рамка акцента)
// code — код              (14px/1.6, моноширинный, фон $code-bg)
```

## 4. Компоненты и состояния

- **Кнопки:** скругление `8px`, padding `10px 16px`, акцентная — заливка `$accent`, текст тёмный; вторичная — прозрачная с границей `$border-subtle`.
- **Карточка новости:** фон `$bg-surface`, граница `$border-subtle`, радиус `12px`, тень при наведении `0 8px 24px rgba(0,0,0,0.4)`.
- **Блоки редактора:** при наведении появляется тонкая рамка `$border-subtle` и тулбар с кнопками (переместить вверх/вниз, удалить). Активный блок — рамка `$accent`.
- **Инпуты:** фон `$bg-elevated`, радиус `8px`, фокус — рамка `$accent`.
- **Бейджи статуса:** «Опубликовано» — зелёный, «Черновик» — жёлтый, «Отложено» — синий. Полупрозрачная заливка соответствующего цвета.

## 5. Анимации

- Переходы: `transition: all 0.2s ease` для ховеров и фокусов.
- Появление карточек: лёгкий fade-up (`opacity 0 → 1`, `translateY(8px) → 0`, длительность 0.25s).
- Колокольчик: при новом уведомлении — лёгкая «встряска» (`keyframes bell-shake`).

## 6. Макет

- **Общий каркас:** слева/сверху — панель навигации (логотип, «Новая статья», колокольчик, профиль), центр — контент (список новостей или редактор).
- **Редактор:** центральная колонка `max-width: 720px` — как колонка Medium. Панель инструментов закреплена сверху при прокрутке.
- **Сетка списка новостей:** `repeat(auto-fill, minmax(300px, 1fr))` — карточки растягиваются адаптивно.

## 7. Рецепты SCSS

Структура стилей фронтенда:

```
frontend/src/styles/
├── _variables.scss   # палитра и типографика (из этого файла)
├── _base.scss        # сброс, фон, базовые стили
├── _components.scss  # кнопки, карточки, бейджи
├── _editor.scss      # блоки редактора, тулбар
└── main.scss         # импорт всех @use
```

> Импорт через `@use` (Sass-модули) — переменные не «протекают» глобально, каждый файл сам объявляет зависимости.
> В Next.js (App Router) корневой `main.scss` импортируется один раз в `src/app/layout.tsx`.

## 8. Адаптивность

- Мобайл: тулбар редактора схлопывается в «+»-меню, навигация — нижняя или скрываемая.
- Тач-области: минимум `44px` высота кнопок на сенсорных устройствах.
