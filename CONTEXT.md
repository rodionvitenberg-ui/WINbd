# WINbd Context

Проект «Редактор новостных статей»: пользователи регистрируются, пишут новости как последовательности блоков и публикуют их немедленно или в назначенное время.

## Language

**Пользователь (User)**:
Человек, который регистрируется в системе и является автором новостей.
_Avoid_: Аккаунт, клиент, профиль

**Новость (News)**:
Статья, написанная автором; состоит из заголовка и последовательности блоков контента.
_Avoid_: Статья-запись, пост, публикация

**Блок (Block)**:
Неделимый элемент содержимого новости (текст, картинка, цитата, код, файл). Новость хранит блоки как упорядоченный массив; порядок блоков определяет порядок отображения.
_Avoid_: Секция, компонент новости, элемент

**Черновик (Draft)**:
Состояние новости, при котором она видна только автору и не попадает в публичный список.
_Avoid_: Незаконченная, скрытая статья

**Опубликовано (Published)**:
Состояние новости, при котором она видима читателям (входит в публичный список новостей).
_Avoid_: Живая, активная, готовая

**Отложенная публикация (Scheduled publication)**:
Механизм, при котором автор указывает дату-время; новость публикуется автоматически при наступлении этого момента.
_Avoid_: Таймер, планировщик, авто-publish

**JWT-токен (JWT)***:
Подписанная строка, которую сервер выдаёт пользователю после входа; содержит id пользователя и срок действия. Используется для доступа к защищённым маршрутам.
_Avoid_: Сессия, ключ, кука

**Право автора (Authorship)**:
Правило, согласно которому изменять или удалять новость может только её автор (пользователь, чей идентификатор совпадает с полем author новости).
_Avoid_: Владелец, модератор

* — термин взят с пометкой «входят в общий контекст проекта, но являются технологией, а не доменным концептом».
